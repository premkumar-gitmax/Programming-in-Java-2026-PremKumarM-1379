# Programming in Java

A collection of Java programs and practical exercises covering Object-Oriented Programming (OOP) concepts, core Java programming, problem-solving, and classroom/practical implementations.

## Topics Covered

- Java Fundamentals
- Classes and Objects
- Constructors
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Interfaces
- Exception Handling
- Arrays and Strings
- Practical Java Programs
